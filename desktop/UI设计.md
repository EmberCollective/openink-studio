# 桌面工作台

界面使用 Tauri 2 + React / TypeScript / Vite，图标来自 Lucide。原生 Rust 负责设备通信、后台转换和文件操作；前端负责可视布局、状态和交互。无 egui 运行入口。

深靛蓝窄导航栏提供工作台、模板库、日志和设置入口。左侧白色卡片编辑页面和内容；中央灰蓝点阵背景上的白纸显示真实路径；右侧完成串口连接、点动、笔控和作业控制。正文控件使用 13–14px，标签 12px，次要说明 11px；侧栏内部滚动。生成预览与任务操作固定在侧栏底部，避免重要操作被长内容挤出。

页面宽高、边距、行数、字号和字间距均参与文字排版，修改后重新生成。画布旋转和大小调整作用于实际路径；旋转后按墨迹边界归一化。视图缩放只改变显示。“适配书写区”明确执行路径缩放，按页面内区和 195mm 最大跨度计算，不在导入后自动缩放。页面显示实际墨迹尺寸和溢出提示。

SVG 直接解析，PDF、PNG、JPEG 及字体中心线转换在 Rust 后台线程执行，避免阻塞界面。PDF 显示总页数并支持选择页转换。阈值默认 180，保守拟合模式独立保留。Python / AutoTrace 路径、DPI、曲线容差可配置。文字来源包括普通 TTF / OTF / TTC、本地中心线字库和原版 gfont。普通字体可从系统列表或文件选择，轮廓与中心线两种模式可选。

原版 gfont 使用独立字体选择模态，支持导入本地文件、搜索、多选、权重、作者/版本/字形数及真实预览路径。原版路径保持字内坐标和笔顺，不经 AutoTrace 或轮廓重建。字号比例、基线、选字种子可调，生成后冻结选字方案。缺字时显示缺失字符并清除可发送文档；确认新字体选择同样清除旧预览，要求重新生成。

模板保存到本机模板库，支持 JSON 导入导出和自定义模板删除。SVG 与轨迹 JSON 可导出；轨迹 JSON 可重新导入，保留图形路径，不宣称恢复字符映射和笔顺。源码窗口只读显示 G-code，可复制和导出。导出的 G-code 使用当前首点相对 XY，Z 仍为绝对坐标，明确要求已手动校准抬笔 Z0。

启动仅扫描串口，自动连接默认关闭。无自动回零、清零或固件修改。点动和抬落笔在连接且 Idle 时启用。作业速率传给后端；点动速率独立限制到 1500。完成状态来自设备事件，停止后提示检查机器和笔尖状态。浏览器预览清楚标注未接入设备，不制造连接、转换或作业数据。

验证：TypeScript / Vite production build 通过；使用 Edge headless 实际检查 1480 × 960 界面截图（.cache/ui-preview-final.png）。没有连接真实机器。Rust 桌面链路仍需独立实机验收，不能以构建或界面截图替代纸面验收。

PDF / 图片转换后，可展开字库提取面板，用原文档 mm 坐标指定单字矩形区域，并手动绑定单个字符。画布选区按同一旋转、缩放及归一化变换显示。字形保存到真实本地字库；文字编辑可切换普通字体与本地中心线字库，缺字由后端明确报错。不声称自动 OCR 或自动恢复字体。

导入区提供阈值 128 默认、180 默认、180 保守和自定义参数。高级参数实际传入 AutoTrace：预平滑次数、曲线拟合误差、直线判定误差、去斑等级；DPI 与路径展平容差独立设置。参数对照弹窗根据当前PDF和所选页面实时生成四组SVG轨迹，每卡显示实际参数并支持缩放与采用。无PDF时提示先上传；换源、换页、改参后清空旧结果，使用请求序号和参数键防止旧响应覆盖新内容。已移除静态comparison.png展示。拟合误差单位px，路径展平误差单位mm；不以顺滑程度替代漏笔检查。
