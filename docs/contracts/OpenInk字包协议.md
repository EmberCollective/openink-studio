# OpenInk 字包协议

`.inkfont` 是 ZIP 压缩包，不是 TTF/OTF。所有信息均为明文 JSON 与 SVG，无厂商字库依赖。

## 使用入口

素材插入的字体来源选择「OpenInk 字库」，打开「字包管理 · 识别入库」。新建或选择字包后，「向此字包新增」进入文件选择、识别拟合、人工校准、确认入库流程。PDF 默认全选所有页面，缩略图支持逐页勾选/取消、全选与取消全选；独立的预览按钮及翻页不改变勾选。一次提交处理全部勾选页，后台逐页执行，避免同时加载多个 OCR 模型。页面预览不依赖 OCR 或 AutoTrace；当前版面提取尚未接入。

批处理显示已处理页数、当前页、成功/失败及复用数。首次处理每页只执行一次 AutoTrace，再按 OCR 字框切分曲线。单页通过 IPC Channel 接收真实阶段进度：页面加载、模型加载、OCR、整页 AutoTrace、按框切分、逐字曲线整理；OCR 与整页 AutoTrace 内部总量未知时显示不定进度与耗时，不伪造百分比。页面失败后继续其他页，重试只处理失败或参数变化页；停止后续页面会等待当前页完成，保留已完成结果。

切字与拟合阶段可切换切字框、拟合曲线、原图叠加预览，并逐字对照切片。人工校准只显示选中字形及附近原稿，直接复用完整笔画编辑器。拖动切字框松手或提交边框数值后自动重新拟合，仍从原图裁取框内区域执行局部 AutoTrace；拖动中、取消或边框未变不触发。改框会清除确认状态并暂时锁定笔画编辑，拟合完成后才能确认；失败可重试，改框与自动拟合可一起撤销到此前编辑。触边、跨框曲线、低可信度和拟合失败优先校准。

人工校准使用窗口内固定布局，候选字、笔迹及属性在各自面板内滚动，底部撤销与确认操作始终可见；完成后的批处理进度在切字与拟合步骤查看。

本次导入期间，每页独立保留最近 100 次校准历史，涵盖边框、字符、笔画、重新拟合、确认及排除。返回步骤或切换已处理页面不会清空结果；未改变素材、页码、参数及模型时不重复 OCR。同页更新参数后重新处理可撤销到先前结果。退出整个导入工具后不保留未入库草稿。

确认入库按素材、页码列出本次仍勾选页面的已确认字形；取消勾选不删除草稿，但该页不参与处理或入库，重新勾选可恢复编辑结果。同一素材同一页仅使用当前保留的一组结果，不重复收录旧参数历史。追加前重新读取当前字包，保留其他操作新增的写法。字符管理可编辑对应字符及笔画，保存只替换该字形 ID；删除可针对单个写法或该字符全部写法。

## 文件与数据

私有构建在字包管理的「导入 .inkfont / .gfont」中支持直接选择 `.gfont`，完整解析后转换并保存为新的 OpenInk 字包，无需 OCR 或逐字确认。原文件不修改，同名字包不覆盖；转换后的字包可编辑、导出，并在不含 gfont 解析器的版本中使用。公开构建不提供 gfont 转换。

转换保留字符、笔画顺序、笔画内点序及全库字形大小比例，空白、控制字符、非 Unicode 标量及无笔迹字形不收录；单点笔画重复该点以保留点状笔迹。全库共用字面：以原 em 为下限，必要时扩大至所有笔迹均落在 75% 基准线上下，再统一缩放至 20 mm 字面；不会逐字拉伸或放大标点。超出原字面的字体在相同字号下可能比原 gfont 小；负向左留边按既有排版规则补偿。转换仍受字包数量、轨迹点数及大小限制，超限或损坏时拒绝保存。

- `manifest.json`：`format: "openink-font"`、`version: 1`、`id`、`name`、`revision`、`variants`。
- `glyphs/<variant-id>.svg`：每份字形的独立中心线 SVG，采用 `M/L` 轨迹，可查看与导出。
- 每个 variant 包含 `id`、`character`、`width_mm`、`height_mm`、`advance_mm`、`strokes`，可选 `canvas: {x,y,width,height}` 保存真实编辑画布；每笔为 `{x,y}` 点数组，至少两个点。
- 同一 `character` 可以有任意多份不同 ID 的字形。字符须为单个非空白、非控制 Unicode 标量。
- 轨迹使用该字形的局部坐标；写字时按 `字号 / height_mm` 缩放。宽度可为零，高度与步进须为正；坐标须有限且位于 `canvas` 范围内。缺少 `canvas` 的旧字形按原 `[0,width_mm] × [0,height_mm]` 校验。画布原点可为负数，宽高须为正且边界有限。SVG 副本以画布左上角为零点导出，manifest 保留原坐标；读取时继续核对两者一致。`advance_mm` 保留为归档兼容字段，OpenInk 字包实际书写按下述笔迹宽度推进，不再由该字段决定字间留白。

与工程包一致，manifest 中轨迹为权威数据，SVG 是精确对应的可检查副本。导入必须验证两者一致；手工修改压缩包内 SVG 不会悄悄覆盖轨迹，应使用应用的字形编辑器保存。SVG 标记不会直接插入浏览器 DOM。

## 生命周期与选字

字形编辑器首次打开旧字形时，以原字面中心向两侧均匀展开为正方形，边长取原字面宽高中的较大值；已有 `canvas` 时直接恢复保存的画布。显示范围就是真实可编辑、可保存范围，包括原字面之外的负坐标区域，OCR 人工校准亦采用同一规则。保存、导出、重新打开均保留画布与全部笔迹。画布与书写尺寸分离，不拉伸或搬移原笔迹，基准线、原字面高度及原始切片映射保持不变，字距仍按实际笔迹推进。仅打开而不保存不改写字包。带扩展画布的字包需使用支持 `canvas` 的版本编辑，旧版本可能因旧边界校验而拒绝读取。

托管目录为 `%LOCALAPPDATA%/OpenInkStudio/inkfonts`，以包 ID 命名。新建空包可保存；增删改通过完整字包提交，并检查 `revision`，防止旧窗口覆盖新改动。成功写入后 revision 加一；同目录临时文件完整写入并同步后再替换，失败保留原文件。

导入得到新的包 ID，保留字形 ID；不会覆盖同名字包。编辑或删除单份字形不影响同字符的其他写法。「删除字包」位于「导出字包」旁，确认后删除本机整个字包，已有画布笔迹保留；需要备份时先导出。旧 `glyph-fonts/*.json` 字库继续支持，未自动迁移或覆盖。

每次生成文字时，每个字符出现位置独立从所选单个字包的全部对应字形中等概率随机选取，允许连续重复；缺字报错，不从其他字包回退。普通排版与沿横线排版均执行此规则。生成后的笔迹即冻结在文档中，后续预览、保存或书写不再抽签。

OpenInk 字包与 gfont 共用横向排版和基准线的几何计算：保留原始正向左留边，仅当笔迹越过左侧零点时向右补偿，推进为 `最大 X − 最小 X + max(最小 X, 0)`，再加排版设置中的字间距。不再按整个字面宽度推进。字形高度、原始大小比例保持不变，汉字和标点均不单独放大。零推进字形以字面高度的 10% 推进。编辑画布在字面高度 75% 处显示可独立开关的基准线；普通排版保留原 Y，沿横线排版将该基准线对齐横线。源坐标、校准原图对照及既有字包文件不变；旧字包无需重新导入。gfont 与旧 JSON 字库的既有输出保持不变。

## 验证边界

包 ID 与字形 ID 仅允许 ASCII 字母、数字、下划线和连字符，长度 1–100。字包名称去空白后非空，最多 300 UTF-8 字节。单包最多 30000 字形、两百万轨迹点，压缩前后各最多 100 MB。

读取拒绝路径穿越、反斜杠、冒号、重复路径、符号链接条目、缺失或额外条目。归档只在内存中解析，不释放任意路径到磁盘。写入拒绝目标为符号链接。仅内部 JSON 与 SVG 被打包，不携带识别来源图片或 PDF。

## IPC

`inkfont_list` 返回 `{id,name,path,characters:string[],variant_count,revision}[]`；`inkfont_load({id})` 返回完整字包。

`inkfont_save({package})` 返回更新后的字包，新建时 `id:""`、`revision:0`；追加、编辑、删除字形均传当前 revision。`inkfont_import({path})` 返回新托管字包；`inkfont_export({id,path})` 导出；`inkfont_delete({id,revision})` 删除整个托管字包。

`list_glyph_fonts` 同时列出旧 JSON 字库和 `.inkfont`；现有 `glyph_font_document` 与 `lined_text_document` 使用返回的路径生成笔迹。

`inkfont_recognize` 的可选 `on_progress` 接收前端 Tauri Channel，消息为 `{stage,done,total}`；`total:0` 表示无法确定总量。阶段为 `rasterize/model_load/ocr/trace/split/curves/done`，最后的 `done` 只在 Rust 曲线解析完成后发布。省略 Channel 时返回值与原接口一致。页面批次由前端编排单页调用，每次调用保留独立进度、结果及失败状态。
