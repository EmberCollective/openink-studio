# PDF底稿与纸面对位

## 导入底稿

左侧「画板 → 导入PDF作为背景」，逐页使用 PDF 实际尺寸；同次导入的相同尺寸页共享一个版面。PDF全页四边映射到画布四边，不额外留边、不按墨迹裁切；保留PDF自带空白。底稿不可框选，不参与书写或轨迹导出，可单独隐藏。

下方翻页区切换页面，各页笔画独立保留，切页清空撤销栈；只书写/导出当前页。完整多页工作区可保存为 `.inkproj`，详见[工程包协议](工程包协议.md)。PDF 直接导入全部页面；照片使用导入、四角拉平净化、确认横线、纸面定位流程，宽高先存草稿，完成后应用，取消还原。

底稿和笔画共用毫米坐标，实际纸张尺寸和打印映射须与画布一致。[Adobe打印说明](https://helpx.adobe.com/acrobat/desktop/print-documents/set-up-and-print-pdfs/page-size.html)：Fit缩放到可打印区域，Actual size不缩放。不能仅凭截图把误差归因于打印机机械偏移。

## 两点校准

入口：左侧「画板 → 纸面定位」。点动、移动速度、指定位置和电动返回位于右侧「设备控制」。

1. 拖动定位点1、2，对准底稿上易辨认的特征；也可展开坐标精确输入。两点须在页面内，至少相距100 mm，尽量隔远以降低对点误差。不要把打印表格边框误当纸张外沿。
2. 手动把笔尖对准第一点，点击确认。软件先验证抬笔，再建立工作坐标，按当前空移速率移向第二点预计位置。
3. 点动微调至纸面第二点，确认后得到统一缩放和旋转；工作原点保持在定位点 1，实际笔尖停在最后确认点（两点为点 2，三点为点 3），不会重置到画布左上角。
4. 版面复用统一使用模板与“应用到页面”，不再提供独立校准方案的命名、保存、选择和应用入口。同一会话所有页面共用工作原点与临时旋转，使用各自版面的比例；换纸后对准相同原点并点击“将当前位置设为工作原点”，无需先重新设置画布原点。纸张比例或方向改变、重连后仍须重新校准。

定位点为透明细十字、编号旁置；拖动时侧边显示以实际定位点为中心的4倍局部窗，松手/取消后收起。显示开关不丢失坐标。拖动不发机器指令；校准/任务期间禁止修改点位。位图放大受源分辨率限制。

历史方案文件及工程内校准字段保留兼容，不删除旧数据，也不自动应用串口坐标或 WCO。手推、换纸或会话失效后须重新确认定位。

## 可选三点校准

默认仍为两点；横纵比例不同或需要独立轴缩放时，在原定位面板选择三点。三点不要求纸张正放。第一点建立临时测量原点，第二点微调后显式确认；此时只保存本次测量，不允许书写。用户继续移向第三点预计位置、微调并确认后才完成校准。第二、第三点确认会先验证抬笔再采集静止位置，不移动 XY；最终确认会同步工作原点；各次移向预计位置沿用先抬笔后 XY 移动流程。

第一点到第二、第三点均须至少 100 mm，两向量夹角的正弦绝对值至少 0.15，避免近共线测量放大误差。后台检查有限数值、抬笔、Idle、本会话 WCO 一致及 A4 软件运动范围；矩阵不得镜像或退化，主轴尺度为 0.1–10。换纸、断连、取消或新建校准使暂存第二点失效。

设备会话的映射使用 `scale`、`rotation_deg` 和可选 `matrix:[a,b,c,d]`。三点测量先求一般二维线性矩阵，完成时提取横纵比例 `hypot(a,c)`、`hypot(b,d)` 和旋转，统一应用 `R(θ)·diag(sx,sy)`；若测量含斜切，明确提示核对贴合效果，不宣称完整保留斜切。工程只保存横纵比例与定位点，不保存会话旋转或 WCO。第三点仍使用可选 `calibration.point3`，兼容旧包。


## 其他定位方式与限制

设备控制恢复工作原点状态与快捷操作，并保留指定点移动与电动返回。两点/三点校准完成即自动生效；手动设置原点使用画布工具栏十字图标或设备控制快捷按钮，点击即先抬笔并执行，不再显示二次确认。指定点移动及返回程序建立的工作原点只由用户主动触发，不使用 `$H`。旧右上角快捷按钮和新建四角定位页入口已移除；独立 [定位 SVG](../calibration/a4-four-corners.svg) 仍可按素材导入。

## 多页比例与临时旋转（2026-10-28）

版面设置复用现有两列数值输入，增加横向/纵向比例（百分数），下方只读显示“本次旋转 · 临时”。比例随工程保存；旋转仅本次连接有效，未校准时显示“待校准”而非 0°。删除反推尺寸及撤销反推入口，PDF、背景、笔画和定位点保持原版毫米坐标；书写映射只应用一次比例。

三点校准完成自动保存当前页的比例；当前页与其他页原先共用版面时拆分当前页配置。已有比例的页面使用两点对位时固定横纵比例，只求当前旋转。重新测量比例选择三点；新照片向导首次两点可测统一比例，不锁定上个页面的比例。

“应用到页面…”是唯一批量入口，复用多页选择对话框，将当前页面尺寸、边距、行数、字号、字间距和横纵比例一起应用到选中页面；未选页面保留原设置，字迹越界时整批拒绝。本次旋转由所有页面共用，不随工程保存。校准和编辑比例本身不改变原版尺寸。

切页采用目标页比例并沿用本次旋转，后台确认软件映射更新后才切页；失败保留当前页及比例。此操作不增加串口指令，不移动机器，不修改 WCO。换纸方向一致时，对准公共工作原点并点击“将当前位置设为工作原点”即可继续；角度改变时做两点对位。

打开工程、断连或恢复连接后旧会话失效，保留各页比例并要求重新校准，已有比例时不能用原点工具绕过。主动修改页面尺寸仍清除定位。软件范围为 X210/Y297 mm，物理行程尚未实测。

⚠️推断（2026-10-28）：同批纸张且放纸方向一致时可复用比例与会话角度；离线映射和模拟设备测试不代表实际纸面精度。构建与验证入口见 [公开与私有构建](公开与私有构建.md)。
