# 前端 UI 一致性规范

用户要求（2026-10-26）：前端风格统一，同类功能统一使用已有元素。此规范适用于后续所有前端新增与修改，不能以“功能已可用”替代样式和交互验收。

## 先复用，再扩展

写界面前先查找现有同类控件及其调用处。已有组件直接复用；多个页面需要同一控件时提取现有实现，不复制成不同版本。不为单个面板再建一套颜色、圆角、控件尺寸或焦点样式。

| 元素 | 统一实现 | 使用要求 |
| --- | --- | --- |
| 开关 | `desktop/ui/src/Toggle.tsx` | 统一 `.toggle-row` / `.switch`，文字在左、开关在右。不得用裸 checkbox 替代同类开关；保留 `aria-pressed` 和键盘操作。 |
| 操作按钮 | `styles.css` 的 `.button` 及现有变体 | 复用常规、主操作和图标按钮样式；同级操作尺寸一致。不能为新面板单独重定义按钮圆角/字体。 |
| 数值输入 | `DraftNumberInput.tsx` | 输入期间保留草稿，失焦后提交和校验；按所在表单复用 `.text-input` 或已有数值输入布局，不实时钳制用户输入。 |
| 文本输入、下拉框 | `.text-input`、全局 `select` | 保持既有边框、背景、字体、禁用和焦点状态。 |
| 辅助说明 | `.field-note` | 简短说明操作结果及必要限制，避免重复说明和大段技术实现。 |
| 可展开详情 | 现有 `details/summary` 样式 | 常用操作直接可见，精确坐标等低频字段默认折叠；展开不能丢失数据。 |
| 画布手柄 | SVG 手柄与现有坐标变换 | 保持屏幕可点击尺寸。定位点中心透明、编号旁置，禁止遮挡底稿；取消 SVG 默认大黑框，但保留局部可见键盘焦点。 |
| 局部放大窗 | `RegistrationHandles.tsx` | 复用画布内容，中心必须是实际定位点；不引入独立坐标映射，不发送机器指令。 |

共享样式入口是 `desktop/ui/src/styles.css`。局部 CSS 只处理专属布局，优先移除与全局样式冲突的覆盖。修改共享组件须检查所有调用处。

侧栏内独立功能块（包括背景向导、选区属性空态）统一复用 `.section` 的内边距，左右留白为 16px；不能直接把表单或标题贴在侧栏边缘，也不要在局部样式中将横向内边距清零。

## 功能区域

- 左侧：素材插入、画板、页面布局与纸面定位；素材追加，不清除已有内容。
- 中央视图上方：选择、拖动、复制、删除、旋转等编辑工具。
- 中央视图下方：历史操作、坐标读数；翻页与缩略图/页面导航集中。
- 右侧：属性、线路规划、设备控制与书写参数；校准点显示开关留在左侧纸面定位区域。
- 右侧使用“属性 / 线路 / 设备控制 / 书写”分页。连接、点动、移动速度、笔控、工作原点、指定点移动和电动返回归入设备控制；纸面定位移至左侧画板的版面设置下方。开始、暂停、停止固定可见。工作原点由纸面校准自动建立，也可用工具栏单图标即时设置。
- 两侧隐藏按钮靠近对应侧栏；高频操作就近，同类操作放在一起。
- 画布顶部的选择、拖动、设置工作原点均为单图标 SVG 按钮，悬停显示说明；设置原点点击后直接执行，不再弹确认。画布只显示有效工作原点，不绘制“默认工作原点”占位标记；末点默认笔尖不能冒充实时机器坐标。

应用顶栏放打开/导出等文件操作；选区属性靠近编辑区；翻页、页码和缩放集中在画布下方右侧，撤销/重做固定在左侧。参考 [Inkscape界面分区](https://inkscape-manuals.readthedocs.io/en/latest/interface.html)，不引入用户已拒绝的标尺。

2026-10-27 更新：窗口使用单层标题栏，文件/编辑位于左侧，中央显示工程名及未保存状态，窗口按钮保留未保存关闭保护，不重复放打开/保存快捷按钮。四角调整直接位于主画布，复用定位点拖拽与放大镜；照片横线确认复用画布选择编辑能力。PDF 继续直接铺好全部页面，不进入照片向导。纸面定位在原面板内默认两点、可选三点，不增加独立页面。

## 验收

交付前检查实际渲染：常态、悬停、键盘焦点、禁用、展开/折叠；坐标、提示和编号不能遮住目标。对拖动检查移动、松开、取消、任务锁；对显示开关检查隐藏后坐标保留。构建或 jsdom 通过不能冒充桌面视觉验收；必须明确尚未检查的部分。用户正在实机测试时，不擅自重启其窗口。

## 放大窗参考

- [Adobe Acrobat Loupe zoom](https://helpx.adobe.com/acrobat/using/adjusting-pdf-views.html)：独立窗口展示选定区域，主文档保持整体视图。
- [Apple Window Zoom](https://support.apple.com/guide/iphone/zoom-in-iph3e2e367e/ios)：窗口式局部放大，支持跟随焦点。

本项目采用拖动定位点时临时显示的 4 倍局部窗，放在画布相对侧，中心留空细十字与坐标读数辅助对位；松手/取消即收起。参考上述交互原则，不复制其整套 UI。位图底稿放大受源分辨率限制，不能凭放大宣称纸面对位精度提高。
