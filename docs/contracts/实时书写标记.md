# 实时书写标记

画布笔画具有独立身份。已写笔画显示绿色，悬停显示「已书写」；后续规划、源码和作业跳过这些内容。框选已写笔画后，上方出现「重置选区书写标记」。标记只保留在当前窗口会话，关闭重开清除；切页、停止任务不会清除已确认标记。

移动/旋转原笔画保留身份和标记；复制/粘贴生成新身份，允许书写。对未写内容应用书写优化保留已写笔画。任务启动后冻结源笔画身份与优化后的顺序映射，动态更新颜色不会重排正在执行的任务。

## 判断来源

遵照用户要求，只使用原有串口回报，不增加 G-code、实时查询或逐笔等待。ACK 是接收进度，不直接标成已写。

软件预先从实际生成的指令建立三维运动线段。收到原有位置回报时，在已发送命令范围中匹配最早可能执行到的线段，仅标记其前方已经结束的完整笔画。交叉/重叠或重复坐标取保守的最早候选；不匹配的位置不推进。原有 Idle 回报与查询前 ACK 前缀用于完成剩余判断，最终任务完成时补齐已提交笔画。

停止后保留已确认完成的笔画；尚未确认完成的当前笔画不整笔标绿，重试可能重描，需要核对。由于只有原有状态采样，标记可能稍晚于真实运动，不能声称连续、逐点、毫秒精确地确认落墨。控制器坐标也不能检测本机物理堵转。

## 验证边界

React 回归覆盖动态颜色、顺序映射、停止保留、再次书写过滤和选区重置；Rust 模拟覆盖连续 Run 和停止，不增加指令或查询。真实落墨与控制器位置仍可能不一致，不能将软件推断当作实机确认。
