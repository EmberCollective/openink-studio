# OpenInk 工程包协议

自桌面版 0.3.0 起，完整工程使用 `.inkproj` 后缀，容器为 Deflate ZIP，私有协议标识 `openink-project`。0.4.2 保存协议版本 `2`，同时读取并迁移版本 `1`；其他版本拒绝打开。应用版本与协议版本分别记录。私有格式不代表加密，包内配置及原始背景可用 ZIP 工具查看。

## 内容

| 路径 | 内容 |
|---|---|
| `manifest.json` | `format`、`version`、`app_version`、`page_count`、`current_page` |
| `pages/N.json` | 可编辑文档、素材归属、笔画 ID、线路应用状态、`layout_id`，以及该页背景引用与预览 |
| `ink/N.svg` | 同页字迹 SVG，坐标单位 mm，不含背景 |
| `config/template.json` | 当前页共享版面的模板字段快照 |
| `config/layouts.json` | 版本 2：共享版面数组，页面通过 `layout_id` 引用 |
| `config/writing.json` | 描线、空移、Z 速率、下探深度、点动步长 |
| `config/routing.json` | 路径优化、反向、连写间距、去重设置 |
| `config/calibration.json` | 原点在画布上的位置、缩放/旋转、两点坐标、显示状态及校准方案 |
| `config/conversion.json` | DPI、阈值、拟合和去斑参数，不含本机 Python/AutoTrace 路径 |
| `config/display.json` | 背景、边距显示状态 |
| `backgrounds/N.pdf`、`backgrounds/N.png`、`backgrounds/N.jpg` | 去重后的背景原文件及处理后图片；无需依赖导出电脑的绝对路径 |

`N` 从 0 开始；背景的 PDF 页码从 1 开始。当前页和空白页均保存，多页共用同一背景时只打包一次原文件。文档 JSON 是可编辑数据的权威来源，SVG 是便于查看、取出的副本。恢复时清空撤销历史、选区和书写完成标记，字迹及素材仍可编辑。

0.4.0 沿用协议版本 1，并兼容旧 PDF 工程。背景增加可选字段：`source_path`（原始资源）、`kind`（`pdf`/`image`）、`corners`（归一化四角）、`processed`、`guides_visible`、`guide_lines`。`path` 引用实际显示的背景；处理后的 PNG 与原图/PDF 分别打包，重新处理使用原始资源。横线由唯一 `id`、毫米坐标 `start`/`end` 表示，保留实际间距与斜率，不补造等距横线。每页文档保存自己的尺寸。

背景不再保存目标 `width_mm`、`height_mm`：目标尺寸的唯一权威来源是页面/版面；PDF 原始页面尺寸由原件重新取得，显示时计算目标/原件比例并拉伸，不另存倍率，也不重新生成拉伸后的 PDF。旧 `.kjoy`/v1/v2 中出现的背景宽高仅作为兼容字段读取并校验与页面一致，重新保存时删除。

每页 `document.text_settings` 保存输入文字面板设置：`text`、`font_mode`、`font_path`、`glyph_path`、`legacy_selection`、`legacy_percent`、`legacy_baseline`、`legacy_seed`、`centerline`、`placement`（`free`/`lines`）、`start_line`、`offset`、`font_size_mm`、`letter_spacing_mm`。该字段可缺省，旧工程继续打开；字迹路径与素材归属仍是已有文字的权威数据。字体路径用于恢复选择，不会把本机字体文件打包，跨电脑再次生成文字需要可用字体。

`text_settings.jitter` 可选保存逐字抖动区间：`x_mm`、`y_mm`（−20～20 mm），`rotation_deg`（−180～180°），`scale_x_percent`、`scale_y_percent`、`scale_percent`（−50～50%，相对原尺寸的变化）。这些字段保存上限，对应的 `字段名_min` 保存下限；下限不能大于上限，相等时取固定值，两端均为 0 时关闭。兼容旧工程：没有 `_min` 时读取为 `[-旧幅度, +旧幅度]`，没有 `jitter` 时全部关闭。每个非空字独立均匀采样区间，绕字形包围盒中心先缩放、再旋转、最后平移；整体缩放与横纵缩放相乘。换行和字距按原排版计算，不因抖动重新分行。每次插入使用新随机种子，生成路径冻结保存，重开、撤销/重做和发送均不重新随机。自由排版沿用画布越界拦截；沿横线排版沿用整行边界校正，无法容纳则拒绝整次插入。

### 段落排版

文字面板的 `line_gap_mm`（0–100 mm）只用于自由排版，行距为「字号 + 行间距」，按纸面可用高度生成行数。字段缺省时兼容原版面的行数设置。沿横线排版隐藏该控件，并始终采用已确认横线的真实间距。

`paragraph_indent`（默认 false）、`indent_chars`（0–10 整数字，默认 2）、`alignment`（`left`/`center`/`right`/`justify`，默认 `left`）由两种排版共用。每个显式换行开启新段落，空行保留；自动折行不重复缩进。首行缩进距离为字数乘以「字号 + 字间距」，与手动空格及字体规则的首字偏移相加。对齐按自由排版的左右边距或当前横线两端计算，斜横线沿线方向移动；两端对齐仅分配自动折行行内的字间余量，单字行与段落末行保持左对齐。启用这些排版设置的自由文字按纸面绝对位置插入，避免素材包围盒重定位抵消对齐或缩进；不重排已有素材。设置随页面保存，旧工程缺省值保持兼容。

### 字体规则集

`text_settings.font_rules` 保存 `{rules, selected}`，最多 50 套；`selected` 为空表示无抖动，否则引用唯一规则 ID。规则保存 `id`、`name`、`general`、`overrides`、`first_offset`、`wave_amplitude`、`wave_length`。覆盖项包含 `characters` 和 `settings`；字符不能重复匹配，未设置的参数继承通用规则。字体文件与规则独立，规则不改写已有笔迹。跨页复用规则时保留当前会话最新定义；工程重新打开以工程内定义为准。

字符参数的 `size`、`stretch_x`、`stretch_y` 为 50–150% 区间（100% 为原尺寸），`spacing` 为 0–200% 的原字间距倍率，`rotation` 为 −180–180°，`horizontal`/`vertical` 为 −20–20 mm。`baseline` 为 −20–20 mm（正值向上），`left`/`right` 为 −20–20 mm 额外留白，负值收紧字距，页面边界检查仍然生效。首字右移 `first_offset` 为 0–20 mm；行基准线正弦波的振幅 `wave_amplitude` 为 0–20 mm、波长 `wave_length` 为 1–500 字。范围均须有限且下限不大于上限。

面板的“恢复默认值”作用于当前选中的规则：通用规则恢复全部通用及整行参数，保留名称和字符规则；字符规则清除单独设置，恢复继承通用参数。保存后写入工程，关闭而不保存则丢弃草稿。

本次文字选区不保存到规则集或工程；前端将 UTF-16 选区转换为 Unicode 标量索引，后端复核 `[start,end)`。无效选区拒绝插入，不回退为全部文字。局部选区仅应用字符设置，不应用整行波动与首字偏移。旧工程中的非零 `jitter` 自动导入为“原有抖动”规则，不改动工程已有路径。

应用规则时，三种字体来源共用沿基准线的逐字排版；自由排版按当前版面的边距、字号和行数生成基准线。变形后的字宽、留白和字间距参与换行，放不下则拒绝整个结果。预览显示真实字形和原排字基准线，不插入画布；预览和每次插入独立随机，插入后的几何结果冻结，路线规划不再抽样。

## 共享版面与旧版迁移

兼容旧版 `.kjoy`：接受 `kenjoy-project` 协议版本 1，通过打开工程、导入文件或启动路径读取，沿用同一校验和版面迁移。首次保存必须选择新的 `.inkproj` 文件，取消则保留当前工程；后端禁止写入 `.kjoy`，不覆盖旧原件。不要求旧应用读取新协议。已用本地历史 `.kjoy` 完成读取、转换、重开与原件不变检查。

每个版面包含 `id`、`name`、`description`、`width_mm`、`height_mm`、`margin_mm`、`font_size_mm`、`letter_spacing_mm`、`lines`；`source` 为 `template`、`manual`、`pdf` 或 `image`。新增成对的 `scale_x` / `scale_y` 保存书写比例（0.1–10）；旧文件缺省时从原校准映射提取。可选 `derivation` 仅兼容旧反推来源：`mode`（`two`/`three`）、`base_width_mm`、`base_height_mm`、`scale_x`、`scale_y`。两点模式的两个比例必须相等，比例范围为 0.1–10；反推信息用于说明来源，后续允许手动调整版面，不强制版面尺寸始终等于原始反推乘积。

版本 2 必须有 1–200 个唯一版面，所有页面必须指向现存版面。页面文档尺寸、背景尺寸（存在时）与该版面一致；缺省背景尺寸按所属版面解释。`template` 必须等于当前页版面的全部模板字段，包括 `id`，但不含 `source`、`derivation`、`scale_x` 和 `scale_y`。文字内容与字体选择仍属于页面；生成新文字时以共享版面的字号、字距、边距和行数为准。

版本 1 不包含 `layouts`，打开时按页面已有宽高精确分组，产生 `layout-N` 标识并补齐页面引用。每组复制旧模板样式；只有旧边距不适用于更小页面时才收窄到短边的四分之一。迁移不缩放、删除或重排字迹，不修改每页文字输入与背景；当前模板快照更新为当前页所属版面。旧背景明确记录的尺寸若与页面冲突，拒绝打开并报告尺寸不一致，避免静默改变底稿。重新保存后使用版本 2，旧应用不保证能打开。

缺失、重复或非法版面引用、无效尺寸/边距、非有限反推数值，以及版面中的未知字段均拒绝读取或保存；保存失败保留原文件。迁移与分配版面不恢复机器会话状态。

## 打开与保存

顶栏“文件”提供新建、打开、保存、另存为与关闭工程，保存全部页面与配置。安装版注册 `.inkproj` 后缀，启动参数中的工程路径也可打开。单独导出 SVG、轨迹 JSON、G-code 保留。

替换未保存工程前提供保存、放弃或取消；取消或读取失败保留当前工作区。后台先校验包内配置和资源，再确认设备允许清除定位，最后替换界面。缺少缓存预览时按背景类型恢复预览；PDF 重新渲染使用 Python/PyMuPDF，0.4.0 完整发行包提供独立运行时。

保存先写同目录临时文件，完成后替换目标；校验、读取原背景、写入失败时保留原工程文件。原背景若在保存前被移动/删除，保存报错，不静默丢弃背景。

## 定位边界

工程保存工作原点在画布上的坐标及各版面横向/纵向伸缩比例，不保存旋转历史；`config/calibration.json` 不写 `rotation_deg`，矩阵只保留对角比例，已退休的方案列表写空，不保存控制器原始 WCO、真实机械位置、连接或运行/暂停任务。笔画完成记录仅用于避免重复书写，不代表机器位置或可恢复的发送队列。打开工程恢复保存的工作原点与共享版面；横纵比例继续用于映射，但不沿用旧旋转和旧笔尖位置。界面提醒用户用两点重新校准当前旋转，不要求三点。

重新打开后需用两点校准确认当前笔尖和旋转，成功后才允许书写。两点校准沿用保存的横纵比例，仅求解当前旋转；重新校准前原点工具不可绕过此限制。

## 页内批次与完成记录

页面文档可包含 `batches: [{id,name,color}]`（1–200 批）、`strokeBatches`（笔画 ID 到批次 ID 的映射）、`writtenStrokeIds` 和 `reviewBatchIds`。没有批次元数据的旧工程按单批读取。默认批次的隐式归属不随排序变化；新复制页面重新生成笔画 ID，并清空完成和中断记录。打开旧复制页时重新映射跨页重复 ID 及其关联归属，防止第一页的完成记录跳过第二页。

属性区可将框选笔画移入本页已有或新批次；线路区管理名称和顺序，属性页和线路页均显示批次颜色，设备控制与书写页恢复普通墨色。归属调整不复制或删除笔迹，支持撤销重做。移除批次必须选择内容接收批次；中断状态必须核对后才可移除，撤销造成归属变化时保留相关笔画的核对要求。

路线计算、对比应用、代码预览及发送队列均仅使用当前批次。其他批次的未写笔画不得在优化替换中丢失。执行和暂停期间冻结目标；完成只选择下一待写批次，不发送下一批。⚠️推断（2026-11-04）：设备现有完成事件要求队列及 ACK 清空、Idle 和 Z0，软件据此标记本批结束；串口模拟通过，新增批次流程仍需实机验收。正常暂停保留本次对位，断线或停止后必须核对未确认笔画，重连仍重新对位；工程打开绝不自动执行。

批次 ID、名称长度、颜色序号、笔画归属和完成/中断引用均在保存和读取时校验，非法引用不覆盖已有工程。批次颜色仅为界面辅助，不代表墨色或换笔，也不进入导出的物理路径。

## 输入校验与限制

最多 200 页、1200 项，压缩文件最多 256 MiB、总解压内容最多 512 MiB、单项最多 128 MiB。拒绝重复 ZIP 路径、路径穿越、反斜杠及盘符路径。背景引用只接受规范的 `backgrounds/N.pdf|png|jpg`，编号小于 400；扩展名须与文件签名一致。解包写入新建临时目录，使用软件生成的文件名。拒绝缺失背景、无效配置、笔画标识不匹配或重复、未知字迹字段及不支持的协议版本。每页横线最多 500 条，ID 唯一，端点有限且在背景范围内、从左到右。预览最多 16 MiB/页，仅接受 PNG data URL。

临时背景保留供当前会话翻页与再次保存使用；它不是用户原文件的持久位置，跨电脑交付应使用 `.inkproj` 包。
