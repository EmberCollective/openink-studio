# 固定机器坐标与纸面对位

2026-11-07 用户修订：操作坐标仅有软件机器坐标与真实机器坐标。纸张可在软件机器背景内摆放；定位点只用于对位，不提供独立工作原点配置。不追溯改变旧 Python 工具。

## 坐标

| 名称 | 方向与定义 |
|---|---|
| 软件机器 C | 背景左上角 `(0,0)`，向右X增大、向下Y增大，单位mm；不随纸张转动 |
| 工作坐标 W | 控制器G54坐标，沿已核对机器方向，Y向上 |
| 定位点 O | 软件机器中的对位锚点；不是第三套坐标系 |

`Wx = Cx - Ox`，`Wy = Oy - Cy`；反向显示笔尖：`Cx = Ox + Wx`，`Cy = Oy - Wy`。

上式为无校准修正时的基础换算；实际使用校准矩阵。纸张局部几何仅供编辑，所有定位点和书写路径经 `machineScene.ts` 转为 C 后发送。预览、导出与作业共用同一转换，后端不接收纸张角度。实时状态和点动不改变 O 或背景原点。

## 操作

“设备控制 → 指定位置与电动返回 → 将笔尖设定在定位点1”复用纸面校准的点1。用户先对准后点击，程序抬笔并核验，不移动 XY；保留已有映射，未完成多点校准时使用当前摆放及页面比例。单点只能确认位置，不能重新测量方向或比例。定位点、校准点不维护两份独立草稿。

### X/Y 轴对调（0.4.5）

在设置中开启“X/Y 轴对调”后再连接设备；设置保存在本机，默认关闭，不写入工程。连接、已连接或恢复期间不能修改，修改前须断开连接。单独修改开关不发送机器命令。

交换仅发生在通信边界：发送的 X/Y 轴字互换，收到的 WPos/MPos/WCO 转回逻辑坐标；Z、速度和实时控制字节保持原义。点动、两点/三点校准、画布笔尖、A4 范围及进度仍用逻辑坐标。G-code 预览和导出使用同一映射。重连仍须重新校准，不沿用旧 WCO。

⚠️推断（2026-10-31）：依据官方配置和模拟通信验证，可用于轴定义交换的颂博士机型；目标机器轴向和物理行程尚未实测。该开关只交换轴，不附带轴反向或原点方位预设。

1. 先将画布摆放与实际纸张对应，在左侧“纸面定位”选择两点或三点，逐点对准并确认；点1用于建立两套机器坐标的映射，最后确认点是当前笔尖。
2. 每次确认点先抬笔，再验证Idle、新鲜位置、WCO和偏移一致；完成映射不额外发送G10。
3. “移动到位置”使用软件机器 X/Y，先完成 Z0 抬笔再走目标；“返回定位点1”返回已确认锚点，不执行 `$H`。
4. 开始书写前需本会话有效校准、Idle、抬笔Z0、工作偏移与校准一致。断连、恢复或意外复位后重新校准，不能复用旧物理位置假设。

手推机械时控制器不会自动感知位移，必须再次校准。软件不自动触发校准、移动或返回原点。

工具栏仅选择定位点1，不运动、不建立坐标系；实际对位由纸面定位中的明确确认触发。移除设备控制中的“将当前位置设为工作原点”和“重置到画布左上角”。

同一摆放下各页沿用本次映射，横纵比例取自各页版面。换纸、改变摆放或重连后重新对位。横放时切换不同尺寸页面使摆放转换改变，旧对位失效。画布仅标记有效定位点，不把定位点标为背景 `(0,0)`。

## 控制器对位锚点

默认工作原点是定位点 1，不是画布左上角。第一点确认建立 G54 XY0；两点/三点完成后保留该原点与已验证 WCO，只更新缩放/旋转或矩阵，不再额外发送 G10 重定位到左上角。笔尖保持在最后确认点：两点校准为点 2、三点校准为点 3。完成前仍须验证空闲、抬笔、有限位置、匹配 WCO 与未取消。失败进入既有恢复流程，旧校准失效。

默认笔尖标记使用末点，只表示默认值，不是实测位置。完成两点/三点校准后自动转为有效映射；书写过程中不增加查询、命令或逐笔等待。控制器 G54 的零点只属于真实机器回报，不重定义背景软件机器原点。

重新打开工程时恢复保存原点和横纵比例，不恢复旧旋转或旧笔尖。两点重新校准从保存矩阵提取 `sx=hypot(a,c)`、`sy=hypot(b,d)`，只求解当前旋转，矩阵为 `[sx·cosθ,-sy·sinθ,sx·sinθ,sy·cosθ]`。版面不再反推尺寸；横纵比例按页保存，旋转仅会话有效且不写入工程。应用比例不缩放源笔画或背景。

⚠️推断（2026-10-27）：上述物理不移动与回零关系由坐标推导及模拟串口验证，仍须实机验收；不是机器实测结论。
