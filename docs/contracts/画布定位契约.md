# 固定画布定位与纸面校准

用户本轮明确要求：纸张与原点固定，点动只移动笔尖；两点/三点校准自动建立工作原点，用户不需要额外确认。此契约取代桌面版旧“每次首笔绑定当前笔尖”的默认行为，不追溯改变旧Python工具。

## 坐标

| 名称 | 方向与定义 |
|---|---|
| 画布 C | 左上角 `(0,0)`，向右X增大、向下Y增大，单位mm |
| 工作坐标 W | 控制器G54坐标，沿已核对机器方向，Y向上 |
| 原点 O | 工作坐标 `(0,0)` 在纸上的固定画布坐标 |

`Wx = Cx - Ox`，`Wy = Oy - Cy`；反向显示笔尖：`Cx = Ox + Wx`，`Cy = Oy - Wy`。

O只在两点/三点纸面校准完成并由后台验证后改变；实时状态、点动、路径导入和编辑都不能改变O。路径首点只是待写位置，不是机器原点。CNC与作业共用同一G54绝对坐标生成器，不能再隐式平移首笔。

## 操作

1. 在左侧“纸面定位”选择两点或三点，逐点对准并确认；点 1 自动成为工作原点，最后确认点是当前笔尖。
2. 每次确认点先抬笔，再验证Idle、新鲜位置、WCO和偏移一致；完成映射不额外发送G10。
3. “移动到位置”先完成Z0抬笔，再走目标XY；“返回原点”同样先提笔，目标为已自动建立的工作原点。没有限位开关，不执行`$H`。
4. 开始书写前需本会话有效校准、Idle、抬笔Z0、工作偏移与校准一致。断连、恢复或意外复位后重新校准，不能复用旧物理位置假设。

手推机械时控制器不会自动感知位移，必须再次校准。软件不自动触发校准、移动或返回原点。

正常纸面校准不要求额外确认。程序承担原点建立与抬笔验证；手动设置原点点击后立即执行，不再显示二次确认。

2026-10-28：本会话的工作原点与临时旋转由全部页面共用，横纵比例取自各页版面，切换页面或新增空白/复制页面不因版面 ID、尺寸不同而清除。换纸后把笔尖对准同一画布原点，直接点击“将当前位置设为工作原点”，保留当前页横纵比例与本次旋转；无需先在画布重新设置原点。此复用要求纸张比例与方向一致；断连、复位或主动重新校准仍使旧会话失效。画布删除“默认工作原点”占位标记，仅显示有效工作原点。

## 纸面校准工作原点（v0.4.2，2026-10-27 用户修正）

默认工作原点是定位点 1，不是画布左上角。第一点确认建立 G54 XY0；两点/三点完成后保留该原点与已验证 WCO，只更新缩放/旋转或矩阵，不再额外发送 G10 重定位到左上角。笔尖保持在最后确认点：两点校准为点 2、三点校准为点 3。完成前仍须验证空闲、抬笔、有限位置、匹配 WCO 与未取消。失败进入既有恢复流程，旧校准失效。

默认笔尖标记使用末点，只表示默认值，不是实测位置；画布不再绘制默认原点占位标记。重新完成两点/三点校准后自动转为有效映射。工具栏设置工作原点点画布后立即先抬笔再设置，不等待二次确认。书写过程中不增加查询、命令或逐笔等待。

重新打开工程时恢复保存原点和横纵比例，不恢复旧旋转或旧笔尖。两点重新校准从保存矩阵提取 `sx=hypot(a,c)`、`sy=hypot(b,d)`，只求解当前旋转，矩阵为 `[sx·cosθ,-sy·sinθ,sx·sinθ,sy·cosθ]`。版面不再反推尺寸；横纵比例按页保存，旋转仅会话有效且不写入工程。应用比例不缩放源笔画或背景。

⚠️推断（2026-10-27）：上述物理不移动与回零关系由坐标推导及模拟串口验证，仍须实机验收；不是机器实测结论。

## 验证边界

校准/走位功能应先用模拟设备验证命令顺序、等待完成、偏移更新和失败恢复，再由用户进行小距离实机验收。原先Python写字成功不能证明新增G10校准与定位链已经实机通过。点动不得改变画布原点；对应历史缺陷记录仅保留在本地研发资料中。
